# Security

Please **don't** open a public issue for security problems. Report them privately with GitHub's
**"Report a vulnerability"** button (Security tab of this repository). We'll reply as soon as we can and credit
you in the fix unless you'd rather stay anonymous.

Things we especially want to hear about: ways a malicious document or `.cerebra` file could run code, read
files outside the library, or leak API keys; and anything that sends your notes somewhere you didn't choose.
See [docs/08-SECURITY-PRIVACY.md](docs/08-SECURITY-PRIVACY.md) for the threat model.
