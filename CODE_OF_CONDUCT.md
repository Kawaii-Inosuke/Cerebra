# Code of Conduct

Cerebra follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be kind, assume good intent, and focus on what's best for the people using Cerebra.
Harassment, insults and personal attacks are not accepted in issues, pull requests, discussions or any other
project space.

To report a problem privately, use GitHub's private reporting on this repository (or contact the maintainers
listed on the repository page). Reports are handled confidentially.
